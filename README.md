# Happy-New-Year

DSH（DeepSeek Harness）相关的 skill、workflow 与 automation 的试验场。

名字是玩闹，用途是把「想到就试」的小自动化沉淀下来 —— 能跑通的再谈复用，跑不通的也留个记录。

## 当前状态

仓库刚初始化：只有本 README 与 LICENSE(MIT)。下面按计划整理，落地一项更新一项。

## 计划目录

按实际需要建立，未落地的目录不预先创建空壳：

- `skills/` —— DSH 可复用的 skill 定义
- `workflows/` —— 多步骤自动化流程
- `scripts/` —— 零散脚本与一次性工具
- `docs/` —— 设计记录与踩坑笔记

## 约定

- 一个想法一个分支，合并时 squash，保证 `main` 上一条记录只讲一件事
- 能复用的才进 `skills/`，一次性试验留在 `scripts/`
- 密钥、内网地址、个人凭据不进仓库
